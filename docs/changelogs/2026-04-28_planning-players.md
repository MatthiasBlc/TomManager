# Changelog - Planning : joueurs et types de table

## 🎭 **Badge JDR / JDS visible sur chaque table**

Chaque table affiche desormais clairement son type en haut a droite : **JDR** en bleu ou **JDS** . Plus besoin d'ouvrir le detail pour savoir de quel type de jeu il s'agit.

## 👥 **Liste des joueurs inscrits dans le planning**

Dans la vue liste, les noms de tous les joueurs confirmes apparaissent directement sur chaque carte, entre le compteur de places et les tags. Dans la vue calendrier, tous les noms sont affiches sur une ligne. Ca permet de voir d'un coup d'oeil qui joue quoi et ou.
