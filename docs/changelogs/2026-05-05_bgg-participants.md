:mag: **Recherche de jeux de societe enrichie**

Vous pouvez maintenant rechercher des jeux directement depuis la base BoardGameGeek (BGG).
Les resultats affichent la photo, le nombre de joueurs, la duree et une description complete avant confirmation.
Une fois ajoute, le jeu conserve toutes ces informations dans votre liste.

---

:game_die: **Fiches jeux plus completes**

Les cartes jeux affichent desormais la description du jeu.
En cliquant sur un jeu (depuis la liste ou depuis une table), une fiche complete s'ouvre avec la description entiere — avec un bouton "Voir plus / Voir moins" si elle est longue.

---

:busts_in_silhouette: **Noms Discord des participants**

La liste des participants affiche maintenant le surnom que chaque personne utilise sur le serveur Discord, plutot que son identifiant de compte.
Les noms sont mis a jour automatiquement a chaque connexion.

---

:twisted_rightwards_arrows: **Tri et filtre des participants**

Il est maintenant possible de trier les participants par nom, date d'inscription ou role, et de filtrer pour n'afficher que les admins ou les membres.
